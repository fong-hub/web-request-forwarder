# Request Forwarder v0.0.9

Release date: 2026-08-18

## Summary

优化配置页规则表格布局，修复同一行内容高度和对齐不一致的问题。

## Highlights

- 扩展配置页工作区宽度，为规则信息提供更稳定的桌面布局
- 重新分配匹配、重定向、类型、状态和操作列宽
- 规则行所有单元格统一垂直居中
- 资源类型保持完整显示，不再发生英文单词断行
- 编辑、复制、删除操作保持同排，避免操作列撑高整行
- 较窄窗口继续使用表格横向滚动，避免压缩内容
