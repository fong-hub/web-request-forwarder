# Request Forwarder v0.0.7

Release date: 2026-08-16

## Summary

优化规则配置与维护体验，并将命中统计调整为当前标签页、当前页面维度。

## Highlights

- 重新命名自动刷新与手动刷新控件，移除“冷 / 热 / 刷”等含义不明确的缩写
- 将匹配类型和重定向类型合并到对应目标配置区，并标注必填与选填字段
- 为现有重定向规则增加复制功能
- 图标徽标按标签页显示当前页面请求命中次数，页面重新加载时自动清零
- 弹窗显示当前页面总命中次数及每条规则的当前页面命中次数
- 使用会话存储保持 MV3 服务进程休眠前后的页面命中状态
