# Request Forwarder v0.0.6

Release date: 2026-05-20

## Summary

新增热更新功能，规则变更后可自动或手动刷新受影响的标签页。

## Highlights

- 🔥 **热更新功能**：规则变更后支持自动刷新受影响的标签页
- 🔄 **手动刷新按钮**：在 Options 和 Popup 中提供「刷新受影响标签」按钮，显示受影响数量
- ⚡ **自动刷新开关**：可开启自动热更新模式，规则变更后立即生效
- 🚀 **绕过缓存**：刷新时自动绕过浏览器缓存，确保新规则立即生效
