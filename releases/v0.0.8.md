# Request Forwarder v0.0.8

Release date: 2026-08-18

## Summary

围绕常见调试任务重做规则创建流程，让用户无需理解 DNR 字段也能创建并验证重定向规则。

## Highlights

- 新增“路径转发”“单个请求替换”“高级规则”三种创建场景
- 路径转发自动保留源地址后的路径，并转换为兼容 Chrome DNR 的正则规则
- 新增实时请求测试，可立即查看是否命中及最终重定向地址
- 弹窗新增“用当前页新建”，自动带入当前标签页地址、本地目标和测试请求
- 自动刷新设置改为本地持久化，MV3 服务进程休眠后仍能保持选择
- 编辑已有规则时保留高级配置，避免自动改写原有匹配表达式
